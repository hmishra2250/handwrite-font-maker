# Nature experiment evidence (2026-09-10)

- `contact-sheet.png`: six real-photo cases and candidate masks, including rejected river results.
- `font-proof.png`: actual generated TTF rendering of the three selected ornament glyphs (`L`, `B`, `F`), not a readable alphabet.
- `nature-experiment-report.json`: measured diagnostics and reproducible prompts. Paths refer to ignored, reproducible `output/` files.
