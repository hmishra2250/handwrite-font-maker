# MVP completion: projects, review, onboarding

Approved direction: finish the capture-to-usable-font journey, not another model. Preserve all existing local changes. No paid deployment, checkout, custom training, or new dependency.

## Contract freeze
- Saved project API `/projects`: GET `{projects:[Project]}`, POST `{name,font,mode,targetCharacters,glyphs,sheet?,lastJobId?}` -> Project201. `/projects/:id`: GET -> Project; PUT full body + `revision` optimistic compare -> Project,409 conflict; DELETE -> `{ok:true}`. Project = body + `id,revision,createdAt,updatedAt,retentionExpiresAt`. IDs server generated. Modes guided/markerless/legacy. Guided projects cannot carry sheets; template projects cannot carry guided glyphs. Empty template drafts may omit a sheet, but cannot build until a sheet exists (and markerless corners are confirmed). Font same FontMetadata. targetCharacters unique printable ASCII33..126 <=94, default ABCDE. Glyph: `{char,inputPhoto,baseline,scale:1,spacing:0,width,height,foregroundRatio,filename}`; optional scale [0.5,1.5], spacing [-0.05,0.25] em. Sheet `{inputPhoto,corners?,cornersConfirmed?}`. lastJobId optional/null must be owned. No blobs/base64 in project JSON.
- Authenticated PostgreSQL projects, owner-scoped references, same tenant admission locks, max10 live projects, 7-day sliding inactivity expiry on successful edits. Keep accepted mask/sheet refs alive through project expiry; do not keep original guided source photos. No artifact/job retention extension implied. DELETE project must not remove files still used by another live job/project. Local mode uses separate atomic JSON project store and existing local objects, clearly single-user development.
- Guided job glyph contracts gain optional scale/spacing as above, defaults unchanged, applied to real exported font metrics (not CSS only). Preserve finite/range validation in Python/Next and server binding.
- Frontend explicit new/open/delete project, debounce serialized autosave, upload each accepted mask once and reuse refs on rebuild; never overwrite remote on revision409, never claim saved on failure. Hydrate accepted PNG blobs on resume; guard stale async loads/saves across project switches/logout. Save modes/sheet refs/font/targets/glyph metrics/lastJobId. Recovery fetches actual job; expiry honest.
- Whole-font review shows target glyphs, missing/accepted/warnings, selected glyph baseline/scale/spacing editing, reuse existing actual generated font proof; adjustments require rebuild and UI says so. Quality warnings are explainable heuristics, not AI confidence.
- Five-character starter + own captures or bundled synthetic sample masks, no model/download dependency; optional full94 selection. Clear handwriting vs experimental ornament positioning.
- Add small opt-in funnel/feedback path without photos/tokens/content in analytics, explicit consent for any image attachment (omit attachments for MVP if no secure consent implementation). Event allowlist, bounded storage/rate limits, no third-party analytics dependency.
- Download package: fonts + character map + installation/readme. Existing help enhanced, no claim of Office testing/automatic OS install.

## Verification
Regression-first targeted tests for project resume/revision conflicts/isolation/ref retention/delete, real exported metric changes, onboarding/autosave failure/stale async guards, feedback privacy, package contents. Full Python (realPG), web unit/type/lint/build, Chromium real starter->save->reload->edit->build->download. Existing markerless/model paths remain working. Hosted/Office/manual capture gaps documented, not fabricated.

## Risks and boundaries
Projects are not build jobs; source retention must use project refs independently. Concurrent tabs conflict explicitly. Partial save/upload failure may leave abandoned24h uploads but must not lose local accepted masks. Template per-character editing is not added without extracting a guided project; markerless/legacy saving restores sheet+corners, not a fictional editable glyph set. Paid billing/account recovery remain separate launch gates.
